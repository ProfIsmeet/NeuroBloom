# Roadmap

> Phase 0 stub. v0.1 scope is tracked phase-by-phase in `PHASES.md`.

## v0.1 (this repository)

Onboarding, profile, 8 avatars, emotion system, tongue/lip exercises, content-driven JSON engine, XP/streak/badges, Letter Wheel mini-game, progress screen, parent dashboard, Premium placeholder, scripted NeuroBot. Fully offline. Turkish-only.

## Beyond v0.1 (not implemented yet)

- Real AI-backed NeuroBot (behind the existing `AssistantEngine` interface)
- Cloud synchronization across devices
- Therapist dashboard and therapist-configured exercise programs
- Real Premium subscriptions/payments
- Additional mini-games (Story Quest — "Magical Garden", Minimal Pairs, Sound Journey, categorization games)
- Additional avatars and English localization
- Advanced personalization and voice/speech analysis

These are explicitly out of scope for v0.1 and are not to be implemented prematurely.
